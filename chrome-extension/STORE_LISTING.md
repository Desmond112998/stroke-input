## Name

筆畫輸入法 Stroke Input

## Summary (132 characters max)

在瀏覽器中用筆畫輸入中文字。按鍵輸入橫豎撇點折五種筆畫，即時匹配候選字，支援詞組聯想。Type Chinese by stroke order in your browser.

## Description

筆畫輸入法 Chrome 擴充功能，讓你直接在瀏覽器的任何文字輸入框中，用筆畫順序輸入中文字。

### 功能特色

- 五種基本筆畫：橫（J）、豎（K）、撇（L）、點（U）、折（I），加上萬用鍵（O）
- 即時候選字匹配，按筆畫數收窄範圍
- 支援多種筆畫寫法（相容 macOS、Nokia 等不同筆順標準）
- 選字後自動顯示常用詞組建議
- 按頻率排序，常用字排在前面
- 候選字分頁瀏覽（空白鍵/Page Down 翻頁）
- 支援所有網頁的文字輸入框、textarea 及 contenteditable 元素
- 輕量設計，只要求 `storage` 權限；使用習慣（字頻／釘選）僅存於本機 `chrome.storage.local`，不上傳伺服器

### 使用方法

1. 按 ` （反引號）開啟/關閉輸入法
2. 按 J/K/L/U/I/O 輸入筆畫
3. 按 1-9 數字鍵選擇候選字
4. 選字後可繼續選擇詞組建議
5. Backspace 刪除最後一筆，Escape 清除所有筆畫
6. Shift 切換中文/英文模式

### 按鍵對照

| 按鍵 | 筆畫 | 名稱 | 符號 |
|------|------|------|------|
| J | 橫 Horizontal | héng | 一 |
| K | 豎 Vertical | shù | 丨 |
| L | 撇 Left-falling | piě | 丿 |
| U | 點 Dot | diǎn | 丶 |

### 例子

輸入「大」：按 J L U（橫 撇 點），然後按 1 選字。
輸入「該」：按 U J J J K I J U J I L L U（點 橫 橫 橫 豎 折 橫 點 橫 折 撇 撇 點），然後按 1 選字。

---

Stroke Input for Chrome lets you type Chinese characters by entering strokes in writing order, directly in any text field on any webpage.

Features:
- Five basic strokes mapped to J/K/L/U/I/O keys, plus wildcard
- Real-time candidate matching as you type strokes
- Compatible with multiple stroke order standards (macOS, Nokia, etc.)
- Phrase suggestions after character selection
- Frequency-ranked candidates
- Works with input fields, textareas, and contenteditable elements
- Lightweight, only the `storage` permission; usage habits stay in local `chrome.storage.local` and are never uploaded

Press backtick (`) to toggle, type strokes, pick candidates with number keys.
